## Memory System

This repository is the durable memory layer for the workspace.

### Core files

- `WORKING_STATE.md`: concise live working log
- `.codex-memory/profile.md`: stable preferences and operating style
- `.codex-memory/operating-mode.md`: canonical assistant working rules
- `.codex-memory/project-schema.md`: template for future project memory
- `.codex-memory/decisions.md`: durable decisions and constraints
- `.codex-memory/active-context.md`: current task state

### Operational folders

- `.codex-memory/issues/`: open and resolved issue memory
- `.codex-memory/history/`: archived memory snapshots and retired notes
- `.codex-memory/history/convention.md`: archive and changelog rules
- `.codex-memory/queue.md`: prioritized pending items
- `scripts/`: helper commands for structured updates
- `.github/ISSUE_TEMPLATE/`: issue templates for memory capture
- `.github/workflows/`: validation workflow for the memory layout

### Rules

- Keep entries factual and short.
- Prefer dates for anything time-sensitive.
- Store secrets nowhere in this repo.
- Update the smallest file that captures the change.
