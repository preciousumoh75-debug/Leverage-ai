# Project Schema

Last updated: 2026-04-28 UTC

## Purpose

Use this schema for any future project memory note.

## Required Fields

- Name
- Status
- Why it matters
- Current goal
- Next action
- Last updated

## Optional Fields

- Owner
- Dependencies
- Risks
- Links
- Archive target

## Recommended Status Values

- Draft
- Open
- Active
- Blocked
- Resolved
- Archived

## Placement Rules

- Put short, urgent items in `.codex-memory/queue.md`.
- Put durable multi-step work in `.codex-memory/issues/open/`.
- Move finished notes to `.codex-memory/issues/resolved/` when done.
- Move long-lived historical context to `.codex-memory/history/` if it should be retained but not actively updated.
