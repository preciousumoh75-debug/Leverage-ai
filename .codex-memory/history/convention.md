# Archive Convention

Last updated: 2026-04-28 UTC

## Rule

- Keep one current copy of active work in `open/`.
- Move completed issue notes to `resolved/`.
- Copy especially important resolved notes to `history/` if they should remain easy to find.

## Changelog Convention

- Log only meaningful changes that affect future context.
- Prefer a short dated bullet instead of a long narrative.
- When a note is retired, update its status and archive path in the file before moving it.

## File Naming

- Use `YYYY-MM-DD-slug.md` for issue notes.
- Use clear, lower-case, hyphenated names for archive notes.
